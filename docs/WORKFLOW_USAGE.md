# 参数筛选与数据集生产

## 输入与配置

`range_2dsft_config()`集中管理所有配置，默认阶段为`preflight`。

- `cfg.data_root`：外部原始回波目录，默认`G:\MATLAB-G\SAR Full PSF`；不复制进仓库。
- `cfg.parameter_file_60`：`inputs/parameters/FS60_params.mat`。
- `cfg.dataset_root`：最终数据集根目录，默认`dataset_range_2dsft/`。
- `cfg.results_root`：辅助结果根目录，默认`results_range_2dsft/`。

代码、数据集和辅助结果目录独立。为支持临时序列的目录提交，生成缓存和最终数据集需要位于同一卷。路径由公共路径函数统一生成。

根目录只保留配置及运行入口，阶段实现和公共算法位于普通`src/`子目录。路径初始化只添加明确的代码目录，不递归扫描数据。成像参数MAT由本机提供，Git不跟踪其二进制内容；参考参数表位于`inputs/reference/`，不会代替搜索和确认。

## 在编辑器中启动

打开根目录的 `start_range_2dsft.m`，直接点击MATLAB编辑器的“运行”。所有常用设置集中在脚本参数区：倍率组、执行阶段、输入输出目录、场景、搜索网格、统计内存及评估并行数。

公共入口执行期间临时将MATLAB当前目录切换到本仓库，正常完成或报错时恢复原目录；这样从旧验证工程目录启动也不会调用那里的同名成像函数。

该脚本的参数区覆盖集中配置中的对应默认值，默认仅处理新增的 `QH=3、QL=2`，阶段为 `all`，会执行完整搜索及生产。只想检查配置时，将 `cfg.stage` 改为 `"preflight"`。中断后保持参数不变，再次点击“运行”即可按断点恢复。脚本执行完后，`cfg`和`workflow_result`保留在工作区，便于查看。

### 选择混合倍率或固定 Q 对照

在同一个启动脚本顶部修改模式，不需要命令行：

```matlab
% H-L-H混合倍率，默认保持原有3/2实验。
cfg.sampling_mode = "hlh";
cfg.search.hl_pairs = [3,2];
```

```matlab
% 固定Q对照：依次搜索、确认、统计、生成及评估三个Q。
cfg.sampling_mode = "fixed_q";
cfg.search.fixed_q_values = [2,2.5,3];
cfg.stage = "all";
```

每次启动只运行所选模式。固定模式不读取`hl_pairs`，混合模式不读取`fixed_q_values`。工厂配置仍默认`preflight`；编辑器启动脚本默认`all`，点击运行会开始实际实验。

固定模式仍然只沿距离维上采样，使用二维SFT阈值。每条连续块只生成一条指定Q的RC分支，九帧均来自该分支，完全跳过H/L能量对齐和空间混合。小数倍率按`round(Q*N)`构建实际采样网格。

每个Q独立搜索一套跨场景和序列共享的STR、fr/Br、fa/Ba，初相位固定0；“全局最优”仅指搜索网格及当前样本上的最优，不保证网格外的数学最优。阈值幅度仍按当前回波块估计尺度。

固定模式采用与混合模式相同的轨迹和序列选择规则；来源及抽样配置相同时，两种模式样本相同。每个候选用搜索样本的单分支九帧ROI拟合场景分位数，每帧只计一次，不使用JointHL。GT在场景内跨候选、跨Q共享。确认只读取搜索拟合统计；正式统计仍按每轨迹10条序列重新计算。

固定模式场景等权，按平均SSIM、最差帧SSIM、平均PSNR、稳定参数键排序。L区SSIM和H/L边界指标为`NaN`（不适用），不参与排序；亮点、梯度、重叠诊断和联系图继续输出。统一入口自动读取该模式的锁定MAT，将最优参数交给统计和生产，无需手动复制阈值。

## 执行阶段

```matlab
cfg = range_2dsft_config();
cfg.stage = "preflight";
run_range_2dsft_workflow(cfg);
```

| stage       | 工作                 | 前置条件        |
| ----------- | ------------------ | ----------- |
| `preflight` | 文件头、协议、样本清单、候选网格预检 | 原始回波和成像参数可用 |
| `search`    | 粗搜索、局部细化和参数锁定      | 自动预检        |
| `confirm`   | 独立样本确认，不重新选优       | 搜索完整完成      |
| `stats`     | 正式场景输入和GT统计   | 确认完成        |
| `generate`  | 所有锁定参数组的LQ/GT生成    | 正式统计完成      |
| `evaluate`  | 最终PNG指标和曲线         | 生成完成        |
| `all`       | 顺序执行全部阶段           | 自动预检        |

统一入口负责阶段前置检查。根目录各`run_range_2dsft_*`阶段函数也可显式调用；其中统计和生成函数需要传入完整参数，评估函数需要参数键，它们不伪造搜索或确认完成状态。

```matlab
% 以下调用将开始实际参数搜索，可能耗时很长。
cfg.stage = "search";
run_range_2dsft_workflow(cfg);
```

## 筛选协议

默认倍率组为`[4,2; 2.5,1.5; 3.25,1.75]`。H/L只改变距离上采样倍率，STR、两方向阈值频率及初相位共享；初相位固定0。

每场景数值排序轨迹后分层抽取7条，第3、5条确认，其余5条搜索，每轨迹一条九帧序列；7场景共35条搜索、14条确认。清单固定保存。若依据确认结果修改搜索方案，应排除已使用的确认轨迹并重新建立独立样本；`cfg.search.exclude_files`接受需排除的轨迹完整路径。

粗网格为STR=`-10:2:10`、两频率=`0:0.2:4`，由H/L共同Nyquist上限及0.98安全余量裁剪，默认594个候选。每组粗选最优点附近以STR偏移`-2:1:2`、频率偏移`-0.2:0.05:0.2`细化，并排除重复候选。所有粗细候选完成后才锁定。

混合模式的L区和边界指标使用与实际成像相同的ROI及512裁剪坐标，保留既有PNG位置。恢复不检查历史指标版本标记；参数一致的已有完整指标和锁定参数直接复用，不因缺少标记强制重算。

每个候选使用搜索样本拟合场景级JointHL统计：能量对齐后的纯H及纯L等像素权重汇总，使用精确midpoint分位数；GT按场景独立统计并共享。确认阶段使用搜索统计，不重新拟合。正式生产按每轨迹均匀10条序列重新拟合，不能复用搜索统计作为正式统计。

指标按最终PNG的uint8口径计算：600 ROI归一化、512裁剪、量化后计算PSNR/SSIM。场景等权，以平均SSIM、L区SSIM、最差帧SSIM、PSNR依次排序，最后按参数键打破并列。亮点、梯度、边界和重叠诊断在[0,1]上计算，未设置硬门槛。确认结果只报告差异，不参与重新选优；这些样本角色不规定恢复模型的训练/测试划分。

PSNR对完全一致帧保留合法的`+Inf`，仍拒绝NaN、负无穷PSNR和非有限SSIM。若某帧位置的算术平均包含`+Inf`，均值保留`+Inf`，标准差不定义；曲线显式标注`+Inf`，不替换为任意有限上限。评估图只保存PNG并关闭内部图窗，避免测试时弹出容易混淆来源的曲线。

## 搜索缓存与恢复

编辑器启动脚本中的`cfg.search_runtime.cache_gb=8`控制搜索和确认会话的缓存上限，单位为GiB。它不限制MATLAB总内存：当前候选的载波、当前场景ROI、分位数排序和FFT临时数组另占内存。32GB机器默认使用8GiB缓存；容量不足时先淘汰最久未使用的上采样结果，优先保留裁剪回波和GT。单项超过预算时只临时计算。缓存随阶段函数退出释放，仍按候选串行调度。

会话按需缓存选中序列的60MHz复回波块，距离FFT插值按序列和实际目标行数复用。每个候选在所有场景间共享载波；每个场景每条序列只采集一次RC：混合模式两分支，固定Q一分支。纯H/L像素用于JointHL拟合，混合ROI用于评价；固定Q同一份ROI用于拟合及评价。搜索分位数直接从内存single像素池计算，评价ROI保持原计算类型，继续使用原裁剪及uint8转换。

GT仍仅用该场景搜索样本拟合，确认样本不会加入统计。归一化后的GT九帧在会话内复用，已有合法GT统计和旧版GT帧缓存也可读取。搜索不再新写归一化像素chunk，不再为每个候选输出联系图；数值诊断保留，代表图只为最终锁定候选及确认输出。正式统计的每轨迹10条序列和像素chunk流程不变。

恢复粒度为“候选×场景”。一个场景全部序列指标成功提交后才算完成，中断最多重算当前场景。候选索引只记录完成位置，恢复时从各场景结果组装指标，不反复写增长的全量表。现有合法完整候选、完整场景及拟合直接复用；旧场景内的部分序列进度允许重算，不迁移或自动删除其像素chunk。恢复只核对实际计算参数，不比较完整运行记录、来源清单、路径、时间戳或版本。缓存容量、统计内存后端及评估并行数是执行选项，改变它们不会使已有进度失效。

搜索和确认分别在自己的报告目录保存`runtime.mat`，记录缓存峰值、回波读取次数、插值次数、RC分支数和命中/淘汰次数。这些是会话累计值；锁定后补代表图所用的少量成像也计入搜索计数。它不代表MATLAB总内存峰值。

## 文件归属

```text
dataset_range_2dsft/<参数键>/
    LQ/<序列名>/000.png … 008.png
    GT/<序列名>/000.png … 008.png
    dataset_metadata.mat

results_range_2dsft/
    protocol/        配置、清单、预检
    search/          排名、锁定参数CSV/MAT
    confirmation/    独立确认表格
    normalization/   正式场景统计MAT
    evaluation/<键>/ 最终指标明细与曲线
    diagnostics/     联系图和结构诊断图
    checkpoints/     搜索、统计、生成、评估进度
    cache/           正式统计像素chunk、未提交PNG及保留的旧缓存
```

混合模式保持上面的辅助目录。固定模式的`protocol`、`search`、`confirmation`、`normalization`、`diagnostics`、`checkpoints`、`cache`各自增加`fixed_q/`子目录；评估仍保存到`evaluation/<参数键>/`。

固定数据集仍直接位于`dataset_range_2dsft/<参数键>/`，例如`range_2d_sft_q2_s0_fr0p2_fa0p2_phi0_lp0p99_hp99p9_roi600`。小数Q编码为`q2p5`；不包含无效的H/L边界缓冲字段。metadata记录固定模式、实际Q、单分支统计及各阶段来源。已有混合数据集和其参数键保持不变。

不使用RunID，不为重复执行创建版本副本。同一参数的完整结果复用，中断续算；参数不符时直接列出字段名、原值和当前值。正式统计成功提交后只清理相应可再生像素chunk。

临时PNG在生成缓存写完整，保存提交断点后再移入最终目录；若在GT/LQ提交之间中断，可依断点继续提交。没有合法断点的残缺序列报错，不自动删除。

数据集metadata记录实际归一化统计和来源，旧metadata原样保留。已有完整PNG按参数键及实际生产参数复用，不回读旧统计文件来核验时间戳或历史版本。评估checkpoint另存，不混入最终指标报告。

## 恢复时只核对实际参数

通用检查点读取函数仅负责读取`state`。各阶段只核对其实际计算参数：采样模式与倍率、STR/频率/初相位、搜索网格及样本量、分位点、ROI、九帧几何和成像核心数值。实际参数不符时报`ParameterMismatch`并列出差异。尺寸、索引、Nyquist、归一化上下限、九帧完整性和必要结果字段检查仍保留，合法`+Inf` PSNR仍可保存及恢复。

不执行完整签名、哈希、schema版本、路径、时间戳、整个FS60或整个metadata比较。历史文件中名为`signature`的字段只用于读取其中已有的实际参数和追溯信息，不作为完整性凭证，也不要求补齐新版本字段。新增检查点只记录必要实际参数和进度，不反复嵌入整个运行记录。来源文件及metadata可继续记录版本、路径和时间，但这些信息不会使恢复失败。

已保存的抽样清单恢复时直接使用，不为签名重新扫描全部原始文件。数据根目录变化时按清单内的场景及文件名定位；不重新抽样。正式统计按场景及参数键复用；评估按序列名恢复，SceneKey等可推导信息直接重新填入，不与旧描述逐项比较。

当前本机旧粗搜索文件缺少后来新增的`metric_protocol`，但其231个候选与当前参数一致。恢复直接使用其中8085条指标，不调用成像、不重新评价，也不改写原检查点。调整历史指标口径需要另行明确重算，恢复操作不会自动执行这件事。

## 检查与小型验证

```matlab
results = runtests("tests");
assertSuccess(results);
```

轻量测试不执行完整搜索或全量生产。成像测试从外部`SAR_Dataset_Bangkok_1/rstart 301.mat`截取第1127列开始的一个2224列原始回波块，在临时目录对Q=2、2.5、3依次执行正式统计、生成和评估；三组使用指定阈值STR=0、fr/Br=1、fa/Ba=0.5，测试结果不是全局最优参数或正式对照成绩。若本机缺少该真实来源，MATLAB将该用例标记为未完成，不改用人工回波替代。

测试还用同源GT检查完美匹配的`+Inf`保存、恢复和非法值拒绝，以及从外部当前目录启动时的函数隔离和恢复。数学与文件恢复单元测试仍使用小型数组；不会用合成冲激回波绘制SAR质量曲线。所有联调产物仅写自身临时目录，结束后清理，不改动现有数据集。

`TestSarSearchRuntime`另从Bangkok场景按正式抽样规则选择5条搜索轨迹和2条确认轨迹，对混合3/2及固定Q=2.5各检查两个指定候选。它将保留的正式chunk统计内核和原逐序列render作为数值基线，对比分位数、uint8帧、全部序列指标和排序，检查场景恢复、旧完整断点、确认不拟合、热缓存不再读取原MAT及每样本RC分支数。测试打印参考流程和新流程的冷/热会话缓存耗时；“冷”仅表示本次MATLAB会话缓存为空，不清除操作系统或硬盘缓存，耗时不是完整搜索时长承诺。

2026-10-16在本机MATLAB R2026a执行上述对照，每模式两个候选为STR=0、2，fr/Br=fa/Ba=0.2，初相位0，缓存上限8GiB。结果如下（单位：秒）：

| 模式 | 参考候选1 / 2 | 新流程冷 / 热缓存 | 两候选合计加速 | 会话缓存峰值 |
| --- | --- | --- | --- | --- |
| H-L-H 3/2 | 57.282 / 36.032 | 26.463 / 13.831 | 2.316倍 | 0.851GiB |
| 固定Q=2.5 | 45.960 / 28.582 | 18.888 / 6.696 | 2.914倍 | 0.503GiB |

缓存峰值包含随后两条确认序列的缓存，不是MATLAB总内存峰值。新旧分位数、uint8帧、序列指标和排序一致；第二个候选未再次读取原MAT或执行距离插值，每候选每样本的RC分支数分别为2和1。20项回归全部通过，修改文件的`checkcode`通过。本次仅为单场景少量候选验证，未执行完整搜索或全量生产。

`range_2dsft_smoke_config(fixture_root, parameter_file)`仍提供单场景、两个粗候选的显式搜索闭环配置，数据和辅助结果分别位于fixture目录下的独立子目录，默认只预检；它与上述单块成像回归不同，不会把一个回波块伪装成独立搜索集和确认集。
